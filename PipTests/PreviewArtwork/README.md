# Earlier dimensional artwork studies

Original generated PNGs retained unchanged as test-only resources. These are not the new
illustrated app assets. The DEBUG `petConceptArtwork` environment injection can render these
in actual app layouts without adding them to any app or widget release bundle.

Created with the built-in image-generation tool from the original three-character concept,
requesting one transparent, full-body, centered penguin/cat/dog each, simpler velvety shapes,
no photographic hair, friendly expression, no props or background. These studies were judged
too realistic; the newer matte illustrated edits and their exact prompt are recorded in
`Docs/Design/Character-direction.md`.
